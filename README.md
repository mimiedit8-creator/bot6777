# Telegram-бот группы РКЛ-3

Бот для группы **РКЛ-3**, 1 курс, специальность 42.02.01 «Реклама», Волжский политехнический техникум.

## Важно
Расписание берётся с официального сайта техникума: https://volpt.ru/. Бот ищет файл или ссылку, содержащую РКЛ-3, скачивает XLSX и показывает строки, в которых указана группа. Если файла нет или формат не распознан, бот честно сообщает об ошибке и не выдумывает занятия.

## Возможности
- Главное меню, звонки, таймер до пары, заметки, ДЗ, факты.
- Утренняя рассылка в 07:30 Europe/Volgograd.
- Напоминание за 15 минут до пары; из-за запуска GitHub Actions раз в 5 минут оно может прийти с задержкой.
- SQLite сохраняется в репозиторий после каждого запуска.

## Установка
1. Создайте бота у @BotFather командой /newbot и получите токен.
2. Создайте репозиторий на GitHub.
3. Загрузите все файлы из архива в корень репозитория.
4. Settings → Secrets and variables → Actions → New repository secret.
5. Имя: BOT_TOKEN, значение: токен бота.
6. Settings → Actions → General → Workflow permissions → Read and write permissions → Save.
7. Actions → RKL-3 bot → Run workflow.
8. Напишите боту /start.

## Ограничение
Расписание звонков пока использует временные интервалы. Когда будет найден официальный файл расписания РКЛ-3, их нужно заменить на расписание техникума.
